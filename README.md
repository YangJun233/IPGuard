# IPGuard

一个常驻系统托盘的 Windows 小工具：定时检测你当前出口 IP 所在的城市，一旦不符合你设定的区域就报警。适用于 **Windows 10 / 11**，**绿色免安装**（单个 `IPGuard.exe`），空闲时内存约 3–5 MB。

> 界面默认英文，可在设置里一键切换中 / 英。

## 功能

- **两类区域规则**，都能选多条、精确到城市，留空即忽略该条件：
  - **禁止区域**：进入其中任意一条就报警。
  - **允许区域**：不在其中任意一条就报警。
- **区域选择用下拉级联**：国家/地区 → 省/州 → 城市（省/州或城市选"全部"= 整个上一级）。
- **异常时可加快检测频率**（秒级），更快发现区域变化。
- **托盘图标一眼看两件事**：
  - 中心圆点 = 地区状态：绿=正常 / 红闪=命中报警 / 黄=已暂停 / 灰=无网络。
  - 外圈圆环 = 网络信号质量：12 点起顺时针，满圈=100，环色由红(差)→绿(好)。
  - 图标随系统 DPI 自适应大小。
- **免打扰**：托盘右键可临时静音（10 分钟起，任意时长），期间照常检测但不弹窗、不闪烁。
- **中英文切换**、**开机自启**、日志自动限制大小并按天清理。

## 下载使用

下载 `IPGuard.exe`，双击即可运行，右下角出现托盘图标。双击图标（或右键 → 设置）进行配置。整个文件夹可拷到别的电脑直接用，删除即卸载。

配置、缓存、日志都写在 exe 同目录：`config.json` / `geo_cache.json` / `ip_guard.log`（均为本地文件，不入库）。

## 从源码编译

需要 Windows 自带的 **.NET Framework 4.x**（Win10/11 均预装），无需安装任何 IDE 或第三方库。在项目目录执行：

```bat
build.bat
```

即用系统自带的 `csc.exe` 编译出 `IPGuard.exe`。源码为单文件 `src/IpRegionGuard.cs`（WinForms，C# 5 语法）。

## 隐私 / 联网说明

- 程序只向公开的 IP 地理查询 API 发普通 GET 请求，问"我的出口 IP 属于哪个城市"，**不上传任何个人数据**。
- 无论处于禁止区还是允许区，请求的地址**完全一样**；禁止/允许的判断在本机完成。
- **网络信号质量不 ping 任何主机**，只用上面那次定位请求的耗时估算，零额外流量。
- 数据来源：定位 `ip-api.com`（主）/ `ipinfo.io`（备）；区域下拉数据 `countriesnow.space`（拉一次后本地缓存）。

## 日志控制（可在 `config.json` 中调整）

| 字段 | 默认 | 说明 |
|---|---|---|
| `LogMaxKB` | 256 | 日志文件大小上限（KB），超出自动删最旧的；`0` = 不限 |
| `LogRetentionDays` | 14 | 日志保留天数，超过自动清理；`0` = 不按天清 |
| `DiagLog` | false | 设 `true` 则每次检测都记一行（排查问题用，日志会变大） |

更多细节见 [使用说明.txt](使用说明.txt)。
