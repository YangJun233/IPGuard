IPGuard — IP 区域守卫（绿色版）
========================================

这是什么
--------
一个常驻系统托盘的小程序：每隔一段时间检测你当前出口 IP 的地理位置，
命中你设定的“禁止区域”或不在“允许区域”时弹窗提醒。适用于 Windows 10 / 11。

绿色免安装：整个程序就是 IPGuard.exe 一个文件。配置、缓存、日志都
写在 exe 所在目录，可以整个文件夹拷到 U 盘或别的电脑直接用。删除文件夹即卸载。

怎么用
------
默认界面语言为英文，可在设置里切换中/英（在“检测与提醒”一行的 Language 下拉，
点“确定”后生效）。下面按中文界面说明。

1. 双击 IPGuard.exe，右下角托盘出现一个“圆点 + 外圈”图标。
   中心圆点 = 地区状态：
   - 绿色 = 正常
   - 红色闪烁 = 命中报警（异常时中心点每秒闪烁，外圈信号保留）
   - 红色常亮不闪 = 命中报警但正处于“免打扰”
   - 黄色 = 已暂停   灰色 = 检测失败/无网络
   外圈圆环 = 网络信号质量：从 12 点起顺时针，满一圈 = 100（信号最好）；
   环色随质量由红(差)→黄→绿(好)。无网络时整圈变灰。鼠标悬停可看具体数值。
   （信号质量只用“每次本来就要发的那次 IP 定位请求”的耗时估算，不额外 ping
   任何主机、不产生额外流量。）
2. 双击托盘图标（或右键 → 设置…）打开设置窗口。
3. 在“选择区域”里用下拉框选：国家/地区 → 省/州 → 城市。
   - 省/州 选“全部”= 整个国家都算命中；城市选“全部”= 整个省/州都算命中。
   - 也可以直接点“当前→禁止 / 当前→允许”，把此刻的位置一键加入。
4. 点“↓ 加入禁止列表 / ↓ 加入允许列表”。可以加多条。
   - 禁止区域：只要处于其中任意一条，就报警。
   - 允许区域：只要不在其中任意一条，就报警。
   - 某个列表留空 = 忽略这个条件。
5. 检测间隔（秒）：
   - 正常检测间隔：正常时多久查一次（最小 5 秒）。
   - 异常区域时改为每 N 秒检测：命中报警后自动切到这个更快的频率，
     以便更快复查/更快提醒；填 0 = 与正常间隔相同（不加速）。
   - 检测到异常即报警，不再有“重复提醒频率”的设置。
6. 勾“开机自动启动”可让它随 Windows 启动。确定即生效。

例：正常 60 秒、异常时 5 秒 —— 平时每分钟查一次；一旦进入禁止/非允许区域，
立刻变成每 5 秒查一次、图标红色闪烁并弹窗，直到你回到正常区域。

何时检测（除定时轮询外，这些情况会“立刻”触发一次检测）：
- 切 VPN / 网卡地址变化、网络通断、睡眠唤醒、解锁 / 远程桌面切换；
- 本机“出口源 IP”变化（每 4 秒本地探测一次，不发包、不耗流量，能抓到双网卡
  路由切换和不少 VPN 静默失效）。
- 事件后若因网络没就绪而查失败，会自动快速重试，不必等下一个轮询。
- 注意：断网（查不到 IP）属于“无网”，不算异常，不会报警、也不会关软件。

异常时关闭程序（可选，默认关）：
- 托盘双击 → 设置 →“异常时关闭程序…”。勾“启用”，用“从运行列表添加 / 浏览 .exe”
  选好要关的程序（名字与任务管理器一致），可多选。
- 处于禁止/非允许区域时，会关闭所选程序，并连同它拉起的插件 / 子进程一并清除。
- 关闭方式：默认“先尝试正常关闭、2 秒后再强制”；勾“立即强制结束”则直接强杀。
- “严格模式”（默认关）：网络一有变动就先把这些程序关掉、再去查 IP —— 最早动手、
  能抢在软件联网前处置；代价是你切到正常网络时也会先关一下。
- 关闭进程不需要管理员权限；但若目标程序是以管理员身份运行的，则需 IPGuard 也提权
  才能关掉它。浏览器插件 / 网页版没有独立进程，只能关掉整个浏览器。

免打扰：不想被打扰时，托盘右键 →“免打扰…”，可选 10 分钟 / 30 分钟 / 1 小时 /
2 小时 / 4 小时 / 8 小时，或“自定义…”（任意时长，10 分钟为最小单位）。
免打扰期间照常检测，图标仍会变红但不闪烁、不弹窗、不出声；菜单里显示剩余时间，
点“取消免打扰”可随时结束。

托盘右键菜单：立即检测 / 暂停检测 / 免打扰 / 设置 / 查看日志 / 退出。

资源占用
--------
- 空闲时物理内存约 3~6 MB（每次检测后主动把内存交还系统）。
- 每次检测只发一个约 0.6~0.9 KB 的 HTTP 请求；60 秒一次一天约 1 MB 流量。
- CPU 几乎为 0：检测就是一次网络请求，等待期间不占 CPU。

文件说明
--------
- IPGuard.exe  主程序（绿色单文件）
- config.json        你的设置（首次保存设置后生成）
- geo_cache.json     国家/省/城市下拉数据的本地缓存（拉过一次就不再联网取）
- ip_guard.log       运行日志（默认只记事件，不记每次检测；自动限大小、按天清理）
- src\ 与 build.bat  源码与编译脚本（自用，不影响运行）

日志控制（在 config.json 里改，改完保存/重启生效）：
- "LogMaxKB": 256        文件大小上限（KB），超出自动删最旧的；0 = 不限
- "LogRetentionDays": 14 保留天数，超过自动清理；0 = 不按天清
- "DiagLog": false       设 true 则每次检测都记一行（排查问题时用，日志会变大）

隐私 / 联网说明
--------
程序只向公开的 IP 地理查询 API 发普通 GET 请求，问“我的出口 IP 属于哪个城市”，
不上传任何个人数据。无论你处于禁止区还是允许区，请求的地址完全一样、行为无差别；
禁止/允许的判断是在本机比较得出的。
- 定位（每次检测）：ip-api.com（主）/ ipinfo.io（备失败才用）
- 区域下拉数据：countriesnow.space（只在设置里选区域时拉一次，之后本地缓存）
- 网络信号质量：不 ping 任何主机，只用上面那次定位请求的耗时估算，零额外流量。

从源码重新编译
--------------
需要 Windows 自带的 .NET Framework 4.x。在本目录执行 build.bat 即可（若 build.bat
因换行问题不生效，可用 PowerShell 直接调用 csc.exe，命令见 build.bat 内的引用）。
